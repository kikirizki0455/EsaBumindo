================================================================================
TEKNOLOGI YANG DIGUNAKAN
================================================================================

BACKEND (esabumindo-backend):
- Framework: NestJS (Node.js Framework)
- Bahasa: TypeScript
- Database: PostgreSQL
- ORM: TypeORM
- File Upload: Multer (Disk Storage)
- Authentication: JWT (JSON Web Token) & Role Based Access Control

FRONTEND (esabumindo-frontend):
- Framework: Next.js (React Framework)
- Bahasa: JavaScript / React (JSX)
- Styling: Tailwind CSS
- HTTP Client: Axios
- Icons: Lucide React
- UI Components: Custom Components (Button, Input, Label, BlockEditor)
